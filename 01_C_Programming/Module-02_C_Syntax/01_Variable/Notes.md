# Lesson 01 : Variable

## Computer Memory (RAM)

ধরো Program শুরু হওয়ার আগে RAM-এর একটি ছোট অংশ এমন দেখাচ্ছে।

```text
               ┌───────────────────────┐
               │    SYSTEM RAM CELL    │
               └───────────┬───────────┘
                           ▼
               ┌───────────────────────┐
       ADDRESS │     MEMORY HOLES      │
       ────────┼───────────────────────┤
        0xa1f7 │ [ ░░░░░░░░ ]  EMPTY   │
        0xa1f6 │ [ ░░░░░░░░ ]  EMPTY   │

        0xa1f4 │ [ █▓▓▒░░░░ ]  FILLED  │
```

RAM হচ্ছে সেই জায়গা যেখানে Program চলার সময় Data সংরক্ষণ করা হয়।

#### Variable আসলে কি ? 
> Variable আসলে হচ্ছে একটি  memory location এর Symbolic নাম ।

```c
printf("Hello");
```
এখানে কোনো Data Save করতে হচ্ছে না। শুধু Screen এ `Hello` দেখিয়ে Program শেষ।
```c
int age = 25;
```
এইবার এখানে ২৫ সংখ্যাটা কোথায় থাকবে CPU তে থাকবে নাকি RAM এ থাকবে ।
এখানে CPU-এর Register খুব ছোট এবং Temporary, তাই কম্পিউটার বলল—আমাকে RAM-এ ছোট জায়গা দাও। এখানে আমরা ধরে নিচ্ছি যে Variable-এর Data RAM-এর একটি নির্দিষ্ট জায়গায় রাখা হচ্ছে।

#### Variable হলো—
RAM-এর একটি নির্দিষ্ট Memory Location-এর একটি Human-readable Name।

## Variable Declaration vs Initialization vs Assignment
অনেকেই এই ৩টা জিনিসকে এক মনে করে। কিন্তু এগুলো আলাদা।

```c
int age;           // Declaration
age = 25;          // Assignment 
```
এখানে আমি variable Declaration করেছি প্রথমে এর পরে আমি Value Assign করেছি । যদি আমি ২টা এক সাথে করতে চাই তাহলে এইটা এমন হবে । 
```c
int age = 25; // Declaration + initialization 
```
এখন দেখা যাক কি করে Variable মেমোরিতে জায়গা দখল করে এর জন্য আমরা এখন কিছু Expriment করব । 

---
### Expriment 01
```c
#include <stdio.h>

int main(void)
{
    int age = 25;

    printf("Address: %p\n", (void *)&age);
    printf("Value  : %d\n", age);
    
    return 0;
}
```
#### Terminal Output
```text
Address: 0x7ffe9b33b62c
Value  : 25
```
এইখানে আমরা দেখতে পাচ্ছি যে আমাদের OS সে আমাদের কে একটি মেমোরি তে জায়গা করে দিয়েছে এবং সেখানে একটি Value সংরক্ষণ করেছে । 
### Question-1
-  এইখানে যদি New Value Assign করা হয় তাহলে কি মেমোরি Address একই থাকবে নাকি বদলে যাবে । 

---
### Expriment 02
```c
#include <stdio.h>

int main(void)
{
    int age = 25;

    printf("Address: %p\n", (void *)&age);
    printf("Value  : %d\n", age);

    age = 30;

    printf("Address: %p\n", (void *)&age);
    printf("Value  : %d\n", age);

    return 0;
}
```
#### Terminal Output
```text
Address: 0x7ffc4d34808c
Value  : 25
Address: 0x7ffc4d34808c
Value  : 30
```
এইখানে আমরা দেখলাম যে,  যদি একটি Variable এর New Value Assign করা হয় তাহলে সেটার জন্য কোনো নতুন Address হয় না । Address একই থাকে Address বদলায় না । 

### Question-2

**যদি `age` একটি মেমোরি Address-এর Symbolic নাম হয়, তাহলে `&age` কেন Address দেখায়?**

**উত্তর:**
এখানে `age` হলো একটি **Symbolic Name**, যা মেমোরির একটি নির্দিষ্ট Address-এ সংরক্ষিত ডেটাকে নির্দেশ করে। অর্থাৎ, প্রোগ্রামে যখন `age` লেখা হয়, তখন আমরা সাধারণত সেই Address-এ থাকা **ডেটার Value**-কে বুঝি।

কম্পিউটারের RAM-এ ডেটা সংরক্ষণের জন্য প্রতিটি মেমোরি Location-এর একটি নির্দিষ্ট **Address** থাকে। Operating System ও Hardware-এর মাধ্যমে এই Address ব্যবহার করে মেমোরিতে ডেটা কোথায় সংরক্ষিত আছে তা শনাক্ত করা হয়।

অন্যদিকে, C/C++-এ `&` হলো **Address-of Operator**। এটি কোনো Variable-এর মধ্যে থাকা Value নয়, বরং সেই Variable-এর **মেমোরি Address** বের করে।

তাই,

* `age` → `age` Variable-এর মধ্যে থাকা **Value** বোঝায়।
* `&age` → `age` Variable-এর **Memory Address** বোঝায়।

অর্থাৎ, `age`-কে যদি মেমোরির একটি নির্দিষ্ট Address-এর Symbolic Name ধরা হয়, তাহলে `&age` সেই Symbolic Name-এর সঙ্গে সম্পর্কিত **প্রকৃত Memory Address** প্রকাশ করে।

## গার্বেজ ভ্যালু (Garbage Value)

এখন আমরা দেখব কোনো ভ্যারিয়েবল ডিক্লেয়ার (Variable Declaration) করার পর মান অ্যাসাইন (Value Assign) না করলে, মেমরিতে থাকা আগের ডেটাকে আমরা কেন 'গার্বেজ ভ্যালু' বলি। বিষয়টি বোঝার জন্য চলুন একটি এক্সপেরিমেন্ট (Experiment) করা যাক।

### Expriment 03
```c
#include <stdio.h>

int main(){
    int var = 10; 
    int val;       

    printf("%d \n",var);   // Initialized Value
    printf("%d \n",val);  // Garbage Value

    return 0;
}
```
এখানে আমরা `int val` থেকে একটি Garbage value পাবো কারন এখানে আমরা কোনো Initialized করিনি তাই এখানে অনির্দিষ্ট value পাওয়া যাবে । তাহলে আউটপুট দেখি । 

### OUTPUT

```text
var : 10 
val : 7098240 // Undefined Value/Random Value
```
তাহলে আমরা দেখতে পাচ্ছি variable কোনো কিছু initialized বা Assigmnt না করলে value এমন উল্টা পাল্টা আসবে । এক কথায় Garbage Value আসবে । 

> ### এখন এইটা দেখা যাক মেমোরিতে কি ঘটলো । 

এখানে আসলে প্রথমে মেমোরিতে *`int val`* **memory** তে জায়গা দখল করেছে `4 byte`। অর্থাৎ Os Memory Reserve করলো `int val` এর জন্য । যখন Assigment করা হবে তখন value ওই reserve Address এ value Store করবে । 

###  Mental Model
```
0xa1f1
0xa1f2
0xa1f3
0xa1f4 --> -1381
0xa1f5 --> 23434
0xa1f6 --> 234
0xa1f7 --> 11234
0xa1f8 --> 34321
```

এখানে যখন মেমোরিতে কোনো ভ্যারিয়েবল শুধু Declare করা হয় (কোনো Value Initialize বা Assign না করা হয়), তখন ওই Address গুলোতে অন্য কোনো প্রোগ্রামের পূর্বে ব্যবহৃত পুরাতন ডেটা বা Value গুলো রয়ে যায়। আচ্ছা, এখন দেখা যাক যখন আমরা কোনো Value Assign করি তখন কী ঘটে। যেমনঃ `int var = 10;` এখানে আমরা মেমোরির **৪টি Address** নিয়ে কথা বলব এবং কাজ করব।

> **এখানে অ্যাড্রেসগুলো ডামি বা কাল্পনিক হিসেবে ব্যবহার করা হয়েছে**

```
0xa1f4 --> 00001010 -> 10
0xa1f5 --> 00000000
0xa1f6 --> 00000000
0xa1f7 --> 00000000
```
এইটা হচ্ছে আসল **মেমোরি ভিউ**। এখানে আমি দেখাতে চেষ্টা করলাম কী করে Value/Data রাখা হয়। এখানে প্রতিটা Address হচ্ছে একেকটি **`8-Bit Cell`** অর্থাৎ **`1 Byte`**। এখন যদি আমরা জিনিসটা আরও পরিষ্কারভাবে বুঝতে চাই, তবে আমাদের এটিকে দেখতে হবে **এন্ডিয়াননেস (Endianness) পদ্ধতির** মাধ্যমে । 

## মেমোরি ভিউ এবং এন্ডিয়াননেস (Endianness)
### এন্ডিয়াননেস (Endianness) কী?

সহজ কথায়, কম্পিউটারের মেমোরিতে (RAM) যখন ১ বাইটের চেয়ে বড় কোনো ডেটা (যেমন 4 বাইটের int) রাখা হয়, তখন তার বাইটগুলো কোন দিক থেকে সাজানো হবে, সেই নিয়মকেই এন্ডিয়াননেস বলে। এটি মূলত দুই প্রকার:

1. Big Endian: সংখ্যার বড় অংশটি (Most Significant Byte) মেমোরির প্রথম বা ছোট অ্যাড্রেসে বসে।
2. Little Endian: সংখ্যার ছোট অংশটি (Least Significant Byte) মেমোরির প্রথম বা ছোট অ্যাড্রেসে বসে। আমাদের আধুনিক কম্পিউটারগুলো (Intel, AMD, ARM প্রসেসর) এই লিটল এন্ডিয়ান নিয়ম ব্যবহার করে।

> #### এখন চলুন দেখা যাক, আমাদের উদাহরণে কীভাবে এই নিয়মটি কাজ করছে।

আমরা দেখলাম মেমোরির 4টি আলাদা খণ্ডে ডেটা উল্টো করে (Little Endian নিয়মে) রাখা আছে। এখন কম্পিউটার যখন এই ভ্যারিয়েবলের মানটি পড়তে যায়, তখন সে মেমোরির বড় অ্যাড্রেস থেকে ছোট অ্যাড্রেসের দিকে বাইটগুলোকে জোড়া লাগায়।
- **ধাপ ১:** সবচেয়ে বড় অ্যাড্রেস 0xa1f7 এর মান (00000000) বসে একদম বামে।
- **ধাপ ২:** তার পাশে বসে 0xa1f6 এর মান (00000000)।
- **ধাপ ৩:** তার পাশে বসে 0xa1f5 এর মান (00000000)।
- **ধাপ ৪:** এবং সবচেয়ে ছোট অ্যাড্রেস 0xa1f4 এর মান (00001010) বসে একদম ডানে।

### বড় সংখ্যার ক্ষেত্রে মেমোরি ভিউ (যেমন: ২৭২৩)

যদি আমাদের ভ্যালুটি বড় হয়, যেমনঃ `int var = 2723;`—তখন এটি মেমোরির একটি মাত্র ঘরেআটবে না। লিটল এন্ডিয়ান (Little Endian) নিয়ম অনুযায়ী সংখ্যার শেষ অংশটি মেমোরির শুরুর অ্যাড্রেসে বসবে এবং বাকি অংশগুলো পরের অ্যাড্রেসগুলোতে ধাপে ধাপে জমা হবে। নিচে এর একটি মেমোরি ভিউ দেওয়া হলো:

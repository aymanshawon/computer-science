- **Mental model first**: ASCII diagrams, flows, analogies/stories (box, Memory City).
- **Experiment-driven**: `gcc -E/-S/-c`, `-O0` vs `-O2`, printing `%p` addresses, `sizeof`, padding tests.
- **Deep "why" questions** that dive into later topics (e.g. `int x = 10` → virtual memory → MMU). See [[parking-lot]].
- **Mistake logging** (`❌ আমি ভাবতাম / ✅ আসল সত্য`) — their most valuable notes.
- Notes are best when in their own words; pasted AI text doesn't stick. See [[feedback]].

**Why:** observed from the whole repo structure and notes (2026-10-03 scan).
**How to apply:** teach Socratically in Bangla+English, one concept per step, give a runnable experiment,
let them write own-voice files and review instead of writing for them.
